The official website for Monocell, the game-making studio that isn't real!

This website was made **without AI** and pure JS, CSS, and HTML. It'll be a tiny bit broken if you have JS disabled, if I had more time I would have made it work a bit better but it is what it is.

There's a lot of cool little things, like the giant wavy rainbow logo (ok maybe that isn't little), the links that become rainbow when you hover them (see the top-right navbar), the icons that become colorized when you hover them (see top-left navbar), the grid background that changes color by section, etc. It's really not too complex of a website though; I just wanted to throw my hand into web development and see what I can actually finish/release.

You can visit the page [here](https://dylhouse.github.io/MonocellWebsite/_).
